# AgentDojo v0.1.35 attribution

ProofMesh's committed public benchmark export is derived from the AgentDojo
`v1` task suites distributed in the `agentdojo==0.1.35` Python package. The
export contains task prompts, injection goals, task identifiers, and normalized
official `ground_truth` tool-call trajectories. It does not contain AgentDojo
model results and does not imply endorsement by the AgentDojo authors.
